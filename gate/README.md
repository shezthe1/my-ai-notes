# 게이트(목록) 화면 시안

아이스크림 기초학력관 › 한국어 위치를 가정한 목록 화면 시안입니다. `index.html`을 크롬으로 열어 봅니다.

- 학년군(큰 탭) → 영역(둥근 탭) → 수준(버튼) → 차시 카드
- 썸네일·'수업 열기'를 누르면 수업이 새 창으로 열림. '차시 정보'는 가운데 모달
- '진단 결과로 찾기': 영역별 도달 수준을 고르면 시작 차시를 보여 줌
- 맨 위 머리글(로고·검색·메뉴)은 위치만 잡은 자리표시. 실제로는 사이트 공통 머리글을 씀

| 파일 | 내용 |
|---|---|
| `catalog.js` | 204차시 목록(커리큘럼 엑셀에서 만듦). `st: open`인 차시만 `lessons/`에 실제 파일이 있음 |
| `lessons/` | `lessons/out/`의 완성 차시를 영문 파일 이름으로 복사한 것(예: 초1~2-듣기-01 → g12-L-01.html) |
| `lessons/sample.html` | 시안에 아직 없는 차시를 누르면 여는 안내 페이지 |
| `img/` | 캐릭터, 수업 첫 화면 썸네일 |

## 한 파일 묶음(보고·시연용)

`python3 bundle.py 학교생활한국어_보고용.html` → 게이트·이미지·수업 6개를 HTML 한 파일(약 4MB)에 담는다.
수업을 누르면 파일 안에 든 수업을 새 창에 써 넣어 연다. 이 파일과 같은 출처라 녹음도 된다.
`lessons/out/`을 다시 빌드했으면 `lessons/`에 영문 이름으로 복사한 뒤 묶는다.
