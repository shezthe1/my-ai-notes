# my-ai-notes

클로드 챗 · 코워크 · 코드 — 우리 팀 업무 가이드

팀원이 Claude의 세 가지 사용 모드(챗, 코워크, 코드)와 관련 기능을 이해하고, 상황에 맞게 골라 쓰도록 정리한 단일 페이지 슬라이드형 가이드입니다.

## 다루는 내용

1. 클로드 챗(Claude Chat): 개념과 업무 시 한계
2. 코워크(Cowork): 내 업무 파일을 직접 다루는 AI, 실무 적용 사례 3가지
3. 프로젝트(Projects): 자주 쓰는 자료를 보관하는 전용 지식 공간
4. 스킬(Skills): 반복 업무용 표준 업무 규칙
5. MCP(Model Context Protocol): 사내 프로그램 연결 커넥터와 설치 예시
6. 클로드 코드(Claude Code): 개발용 에이전트
7. 챗 vs 코워크 vs 코드 비교, 상황별 선택 기준
8. 코워크 시작 2단계, FAQ, 3줄 요약

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 가이드 본문. 슬라이드 전환과 진행 바를 포함한 단일 HTML 파일 |

## 사용 방법

빌드 과정이 없습니다. `index.html`을 브라우저에서 열면 됩니다.

## 기술 스택

- HTML / JavaScript (단일 파일)
- [Tailwind CSS](https://tailwindcss.com) (CDN)
- [Lucide](https://lucide.dev) 아이콘 (CDN)
- [Pretendard](https://github.com/orioncactus/pretendard) 폰트 (CDN)

CDN을 사용하므로 인터넷 연결이 필요합니다.
