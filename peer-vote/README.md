# 동료 상호평가 투표 (구글 앱스 스크립트)

로그인 없이 **닉네임 + 숫자 4자리 비밀번호**로 투표하는 웹 앱입니다. 응답은 팀장 구글 시트에 쌓입니다.

- `Code.gs`: 서버 코드(저장, 비밀번호 확인, 결과 집계). 맨 위 설정만 고치면 됩니다.
- `Index.html`: 투표 화면과 팀장 결과 화면.

## 설치 (약 10분, 한 번만)

1. 구글 드라이브에서 **새 구글 시트**를 만듭니다. 이름 예: `동료 상호평가 응답`
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣습니다.
4. 맨 위 `OWNER_PASSWORD`를 **6자 이상의 팀장 비밀번호**로 바꿉니다. 결과 화면을 여는 비밀번호입니다.
5. 왼쪽 **파일 옆 + → HTML**을 눌러 이름을 `Index`로 만들고(확장자 없이), 이 폴더의 `Index.html` 내용을 붙여 넣습니다.
6. 저장(디스크 아이콘 또는 Ctrl+S)합니다.
7. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 유형 선택(톱니) → **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누릅니다.
8. 권한 승인 창이 뜨면 **액세스 승인 → 내 계정 선택**을 누릅니다. "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누릅니다. 내가 만든 스크립트라서 나오는 경고입니다.
9. 나온 **웹 앱 URL**(`…/exec`로 끝남)을 복사합니다.

## 쓰는 방법

| 용도 | 주소 |
| --- | --- |
| 투표 (팀원·팀장) | 웹 앱 URL 그대로 |
| 결과 (팀장만) | 웹 앱 URL 뒤에 `?view=result` |

- 팀장도 투표 주소로 들어와 본인 닉네임으로 투표합니다.
- 같은 닉네임과 비밀번호로 다시 들어오면 이전 응답이 불러와지고, 다시 제출하면 덮어씁니다.
- 비밀번호를 5번 틀리면 그 닉네임은 10분 동안 잠깁니다.
- 테스트 응답은 시트의 `응답` 탭에서 해당 **행을 삭제**하면 됩니다.

## 코드를 고친 뒤

**배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 누릅니다. URL은 그대로 유지됩니다. (새 배포를 만들면 URL이 바뀝니다.)

## 알아 둘 점

- **익명성**: 결과 화면에서는 닉네임 목록과 투표 내용이 따로 보입니다. 하지만 시트에는 닉네임과 투표가 같은 행에 저장되므로, 시트를 열면 누가 누구를 골랐는지 볼 수 있습니다.
- **중복 투표**: 닉네임을 바꿔 가며 여러 번 투표하는 것은 막지 못합니다. 결과 화면의 "제출 7명 / 전체 7명"과 닉네임 목록으로 확인하세요.
- **회사·학교 계정**: 관리자 정책으로 "모든 사용자" 배포가 막혀 있으면 이 선택지가 보이지 않습니다. 그때는 개인 구글 계정으로 시트를 만드세요.
- 화면 위쪽에 "Google이 아닌 다른 사용자가 만든 애플리케이션" 안내 띠가 보입니다. 앱스 스크립트 웹 앱에 항상 붙는 안내입니다.
