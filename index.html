비개발자를 위한 IT / 클로드 용어 사전

일상 비유로 쉽게 풀어쓴 핵심 용어 설명

프로젝트 (Projects)

자주 쓰는 사내 규정집, 문서 양식, 지침 등을 한곳에 모아두는 '팀 전용 지식 서고'입니다. 대화할 때마다 자료를 매번 다시 올릴 필요가 없습니다.

스킬 (Skills / 행동 규칙)

"우리 팀 보고서 양식대로 변환", "외국어 이메일 톤 교정" 등 AI가 특정 업무를 수행할 때 따르는 '표준 작업 공식'입니다.

1턴(1-Turn) 대화

질문 1개에 답변 1개로 끝나는 일회성 질의응답 방식입니다. "이거 번역해 줘" 하면 "네, 번역 결과입니다"로 끝나는 일반 챗봇과의 대화입니다.

MCP (Model Context Protocol)

AI와 외부 업무 앱(슬랙, 구글 드라이브, 노션 등)을 안전하게 이어주는 '표준 멀티탭 / 연결 단자'입니다. 어려운 개발 없이 커넥터만 켜면 앱 속 자료를 클로드가 즉시 읽어옵니다.

터미널 (Terminal)

마우스 클릭 없이, 검은색 화면에 영어 명령어(글자)를 직접 쳐서 컴퓨터를 제어하는 개발자용 명령창입니다.

IDE (통합 개발 환경)

우리가 문서 작성할 때 '한글'이나 'MS 워드'를 쓰듯, 개발자들이 소스코드를 작성하고 검토할 때 쓰는 '개발자 전용 워드 프로그램'(예: VS Code)입니다.

디버깅 (Debugging)

프로그램 코드 속에 숨어 있는 오작동 원인이나 오류('벌레(Bug)')를 찾아내어 말끔히 수리하는 작업입니다.

커밋 (Commit)

작성하거나 수정한 코드 작업물을 "이 버전으로 정식 승인 및 저장합니다!"라고 도장을 찍어 최종 기록 저장소에 남기는 행위입니다.

백그라운드 실행 (Background)

내가 화면을 계속 쳐다보고 있지 않고 다른 일(메일 확인, 회의)을 하고 있어도, 컴퓨터 뒷단에서 AI가 혼자 묵묵히 다단계 작업을 진행해 놓는 상태를 말합니다.

액션 아이템 (Action Item)

회의나 논의 결과 도출된 '누가, 언제까지, 무엇을 완수해야 하는지' 정해진 구체적인 실행 과제 목록입니다.
